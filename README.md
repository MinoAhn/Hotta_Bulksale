## 使用流程：

1. 解压后双击exe文件

![img_5.png](img_5.png)
2. 打开游戏并进入商店上架界面，需要`全屏`或者`窗口化全屏`（最大化也可以）。

![img_4.png](img_4.png)
3. 点击扫描界面，窗口会自动最小化扫描商店页面

![img_6.png](img_6.png)
通过log观察扫描是否能识别到背包/上架区域材料

![img_7.png](img_7.png)
4. 识别完成后设定好商品价格，以及打开需要操作的商品开关

![img_8.png](img_8.png)
5. 选择 `开始上架`，或 `下架所选`
